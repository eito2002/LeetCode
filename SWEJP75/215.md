# [215. Kth Largest Element in an Array](https://leetcode.com/problems/kth-largest-element-in-an-array/description/)

## step 1

priority_queueを使う典型的な問題(Arai60ではそこに分類されていたためそう認識)
```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        priority_queue<int, vector<int>, greater<int>> minHeap;
        for (int n : nums) {
            minHeap.push(n);
            if (minHeap.size() > k) {
                minHeap.pop();
            }
        }
        return minHeap.top();
    }
};
```

### 主な解法と特徴

| 手法                       | 概要                                          | 時間計算量            | 空間計算量         |
| ------------------------ | ------------------------------------------- | ---------------- | ------------- |
| 1. ソート                   | `nums` を降順（または昇順）ソートし、添字 `k-1` を返す          | O(n log n)       | O(1) または O(n) |
| 2. ヒープ（優先度付きキュー）         | 小さい方から k 個を維持するミニヒープを使う                     |  O(n log k)        |  O(k)         |
| 3. Quickselect（選択アルゴリズム） | 平均 O(n) の分割統治法で、pivot を使い k 番目の位置に値を移動しつつ探索 | 平均 O(n)、最悪 O(n²) | O(1)          |

### STLを使用した解法
```cpp
class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        int n = nums.size();
        nth_element(nums.begin(), nums.begin() + (n - k), nums.end());
        return nums[n - k];
    }
};
```
`nth_element`が自動でQuickSelectとヒープソートを切り替えて、昇順ソート時の (n-k) 番目に置いてくれる。
速度もとても速い。
